MACD背离策略回测分析：为什么最终被否决

2026-10-01 量化策略

MACD背离是技术分析里被讲得最多的形态之一。顶背离看跌、底背离看涨，逻辑直观,画图也好看。但把主观判断翻译成可回测的规则后,结论往往不那么美好。

本文记录一个MACD背离策略从实现到否决的完整过程,包含三层验证:信号触发率稳定性、参数敏感性、以及在不同市场状态下的表现。结论是:这个策略被否决,不是因为亏钱,而是因为不可靠。

一、MACD背离的原理与量化难点

1.1 背离的定义

MACD由三部分组成:

  • DIF(快线)= EMA(close, 12) - EMA(close, 26)
  • DEA(慢线)= EMA(DIF, 9)
  • MACD柱 = 2 × (DIF - DEA)

背离指的是价格与MACD指标走势相反:

  • 顶背离:价格创新高,MACD的DIF(或柱)未创新高
  • 底背离:价格创新低,MACD的DIF未创新低

1.2 量化背离的难点

人眼看图判断背离很容易,但写成代码时会遇到几个模糊点:

  1. "高点"如何定义:是局部极值?窗口内的最大值?还是ZigZag转折点?
  2. 比较哪个指标:DIF、DEA还是MACD柱?三者结论可能不同
  3. 时间窗口多长:两个高点之间隔多少根K线算有效?
  4. "创新高"的幅度:差1个tick算不算?

这些模糊点每一个都会显著影响信号数量。我们采用最常见的方案:用scipy.signal.argrelextrema找局部极值,比较DIF,窗口设为20根K线。

二、策略实现

2.1 数据与指标计算

import numpy as np
import pandas as pd
import akshare as ak
from scipy.signal import argrelextrema

def get_data(symbol="sh000300", start="20200101", end="20241231"):
    df = ak.stock_zh_index_daily(symbol=symbol)
    df["date"] = pd.to_datetime(df["date"])
    df = df[(df["date"] >= start) & (df["date"] <= end)].reset_index(drop=True)
    return df

def compute_macd(close, fast=12, slow=26, signal=9):
    ema_fast = close.ewm(span=fast, adjust=False).mean()
    ema_slow = close.ewm(span=slow, adjust=False).mean()
    dif = ema_fast - ema_slow
    dea = dif.ewm(span=signal, adjust=False).mean()
    hist = 2 * (dif - dea)
    return dif, dea, hist

2.2 背离信号识别

def find_divergence(df, order=5, lookback=20):
    """
    order: 局部极值窗口
    lookback: 两个极值之间的最大间隔
    返回: 信号序列, 1=底背离买入, -1=顶背离卖出
    """
    close = df["close"].values
    dif = df["dif"].values
    n = len(df)
    signal = np.zeros(n, dtype=int)

    # 找价格和DIF的局部极值
    price_lows = argrelextrema(close, np.less, order=order)[0]
    price_highs = argrelextrema(close, np.greater, order=order)[0]
    dif_lows = argrelextrema(dif, np.less, order=order)[0]
    dif_highs = argrelextrema(dif, np.greater, order=order)[0]

    # 底背离: 价格新低, DIF未新低
    for i in range(1, len(price_lows)):
        cur = price_lows[i]
        for j in range(i - 1, -1, -1):
            prev = price_lows[j]
            if cur - prev > lookback:
                break
            if close[cur] < close[prev]:
                # 找两个低点之间最近的DIF低点
                d1 = dif_lows[np.abs(dif_lows - prev).argmin()]
                d2 = dif_lows[np.abs(dif_lows - cur).argmin()]
                if dif[d2] > dif[d1]:
                    signal[cur] = 1
                break

    # 顶背离: 价格新高, DIF未新高
    for i in range(1, len(price_highs)):
        cur = price_highs[i]
        for j in range(i - 1, -1, -1):
            prev = price_highs[j]
            if cur - prev > lookback:
                break
            if close[cur] > close[prev]:
                d1 = dif_highs[np.abs(dif_highs - prev).argmin()]
                d2 = dif_highs[np.abs(dif_highs - cur).argmin()]
                if dif[d2] < dif[d1]:
                    signal[cur] = -1
                break
    return signal

2.3 简单回测框架

def backtest(df, signal, hold=10):
    """
    信号出现后次日开盘入场,持有hold根K线后平仓
    """
    df = df.copy()
    df["signal"] = signal
    trades = []
    i = 0
    while i < len(df) - hold - 1:
        if df["signal"].iloc[i] != 0:
            entry_idx = i + 1
            exit_idx = min(i + 1 + hold, len(df) - 1)
            entry = df["open"].iloc[entry_idx]
            exit_ = df["open"].iloc[exit_idx]
            direction = df["signal"].iloc[i]
            ret = (exit_ - entry) / entry * direction
            trades.append({
                "entry_date": df["date"].iloc[entry_idx],
                "direction": "long" if direction == 1 else "short",
                "return": ret,
            })
            i = exit_idx
        else:
            i += 1
    return pd.DataFrame(trades)

三、三层验证

3.1 第一层:信号触发率

先看信号数量是否稳定。一个策略如果一年出3个信号、下一年出80个信号,说明它对市场环境极度敏感,统计意义很弱。

df = get_data()
df["dif"], df["dea"], df["hist"] = compute_macd(df["close"])
signal = find_divergence(df)
df["signal"] = signal

yearly = df.groupby(df["date"].dt.year)["signal"].apply(lambda s: (s != 0).sum())
print(yearly)

波动范围7到22,标准差约6。这个波动本身不是问题,问题在于它和策略表现没有稳定关系——2022年信号最多,但当年是单边下跌,底背离频繁失效。

3.2 第二层:参数敏感性

把order和lookback两个参数做网格扫描:

results = []
for order in [3, 5, 8, 10]:
    for lookback in [10, 20, 30, 50]:
        sig = find_divergence(df, order=order, lookback=lookback)
        trades = backtest(df, sig, hold=10)
        if len(trades) == 0:
            continue
        win_rate = (trades["return"] > 0).mean()
        avg_ret = trades["return"].mean()
        results.append({
            "order": order,
            "lookback": lookback,
            "n_trades": len(trades),
            "win_rate": round(win_rate, 3),
            "avg_return": round(avg_ret, 4),
        })

res_df = pd.DataFrame(results)
print(res_df.pivot(index="order", columns="lookback", values="avg_return"))

结果(平均单笔收益):

order\lookback 10 20 30 50
3 0.0012 -0.0008 0.0021 -0.0015
5 -0.0021 0.0018 -0.0009 0.0006
8 0.0034 -0.0022 0.0011 -0.0003
10 -0.0018 0.0009 -0.0025 0.0017

正负号在参数空间里随机跳变,没有任何稳定区域。这是典型的过拟合信号:你在某个参数上看到盈利,换一组参数就变成亏损,而两组参数在逻辑上没有本质区别。

3.3 第三层:分市场状态表现

把回测区间按趋势和震荡切分,看策略在不同环境下的表现:

# 用60日均线的斜率定义市场状态
df["ma60"] = df["close"].rolling(60).mean()
df["ma60_slope"] = df["ma60"].diff(5)
df["regime"] = np.where(df["ma60_slope"] > 0, "up",
                np.where(df["ma60_slope"] < 0, "down", "flat"))

trades = backtest(df, signal, hold=10)
trades["entry_date"] = pd.to_datetime(trades["entry_date"])
trades = trades.merge(df[["date", "regime"]], left_on="entry_date", right_on="date")

print(trades.groupby(["regime", "direction"])["return"].agg(["count", "mean"]))

结果:

regime direction count mean
up long 12 0.008
up short 9 -0.011
down long 21 -0.014
down short 8 0.006
flat long 6 -0.002
flat short 5 0.001

关键发现:

  1. 底背离在下跌趋势中频繁出现,且多数失败。这符合直觉:下跌趋势里价格不断新低,DIF也不断新低,偶尔一次"未新低"就触发信号,但趋势没结束。
  2. 顶背离在上涨趋势中做空,平均亏损。上涨趋势中的顶背离几乎都是假信号。
  3. 真正赚钱的组合是"上涨趋势中的底背离做多",但样本只有12笔,统计上不显著。

四、否决原因分析

三层验证后,策略被否决,原因归纳为三点:

4.1 触发率不可控

背离信号的数量和位置高度依赖极值识别算法。argrelextrema的order参数从5改到8,信号数可能变化30%以上。这意味着策略的"入场时机"本质上是由参数决定的,而不是由市场结构决定的。

4.2 参数空间无稳定区域

网格扫描的结果显示,平均收益在参数空间里正负跳变,没有连续的盈利区域。这类策略即使在某组参数上回测好看,也无法保证样本外有效。稳定的策略应该在参数空间里有"高原"而不是"针尖"。

4.3 信号方向与趋势相悖

背离本质上是反转信号,而市场大部分时间处于趋势中。在趋势市场里做反转,胜率天然偏低。如果加上趋势过滤(只在上涨趋势中做底背离),样本量又太小,无法支撑统计结论。

4.4 一个补充观察

我们还测试了"背离+MACD金叉"的组合过滤,想通过双重确认提高胜率。结果是信号数减少到原来的1/3,但胜率只从48%提升到52%,平均收益仍然不显著。过滤条件解决不了根本问题:背离本身不携带足够的预测信息。

五、经验总结

这个策略的否决过程比结论更有价值:

  1. 主观形态量化后,先看触发率稳定性。信号数在不同年份、不同参数下剧烈波动,说明规则本身不稳健。
  2. 参数敏感性测试是必做项。如果参数空间里没有连续盈利区域,基本可以判定是过拟合。
  3. 分市场状态回测。一个策略如果在趋势市和震荡市表现差异巨大,需要明确它的适用场景,否则就是碰运气。
  4. 不要用过滤器掩盖问题。加过滤条件后如果胜率提升有限、样本量骤减,说明原始信号质量就不够。

MACD背离不是不能用,但它更适合作为辅助确认而非独立入场信号。单独拿它做策略,回测数据不支持。
