模拟交易系统架构设计：从信号扫描到自动执行

2026-09-16 Python自动化

做一个模拟交易系统，最怕的不是策略不赚钱，而是架构混乱——信号、分析、执行、通知四块逻辑搅在一起，改一个参数要动五个文件。这篇文章拆解一套我正在用的架构，四个模块各司其职，通过明确的数据流串联。

整体架构

先看全局。系统采用事件驱动 + 定时轮询的混合模式：

┌─────────────────────────────────────────────────────┐
│                    Scheduler (APScheduler)           │
│              定时触发 / 事件驱动                      │
└──────┬──────────────────────────────────────────────┘
       │
       ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  信号扫描模块  │───▶│  市场分析模块  │───▶│ 模拟交易引擎  │
│ SignalScanner│    │MarketAnalyzer│    │ TradeEngine  │
└──────────────┘    └──────────────┘    └──────┬───────┘
       │                    │                   │
       │                    │                   ▼
       │                    │            ┌──────────────┐
       │                    │            │  推送通知模块  │
       │                    │            │  Notifier    │
       │                    │            └──────────────┘
       ▼                    ▼                   ▼
┌─────────────────────────────────────────────────────┐
│              数据层 (SQLite + 内存缓存)               │
└─────────────────────────────────────────────────────┘

数据流向很清晰：扫描 → 分析 → 执行 → 通知，单向流动，不回头。每个模块只依赖数据层，模块之间通过数据结构（dataclass）通信，不直接调用。

模块职责划分

模块 职责 输入 输出
SignalScanner 拉取行情、计算指标、产生原始信号 行情API List[Signal]
MarketAnalyzer 过滤信号、评估市场状态、打分 List[Signal] List[TradeIntent]
TradeEngine 模拟下单、持仓管理、盈亏计算 TradeIntent TradeResult
Notifier 格式化消息、推送 TradeResult 通知

关键原则：每个模块可以独立测试。SignalScanner 不需要知道 TradeEngine 的存在。

数据模型定义

先用 dataclass 把模块间的通信协议定死：

from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Optional

class SignalDirection(Enum):
    LONG = "long"
    SHORT = "short"
    CLOSE = "close"

@dataclass
class Signal:
    """信号扫描模块的输出"""
    symbol: str
    direction: SignalDirection
    price: float
    indicator_values: dict
    timestamp: datetime = field(default_factory=datetime.now)

@dataclass
class TradeIntent:
    """市场分析模块的输出，准备执行的意图"""
    symbol: str
    direction: SignalDirection
    price: float
    confidence: float  # 0~1
    reason: str
    timestamp: datetime = field(default_factory=datetime.now)

@dataclass
class TradeResult:
    """交易引擎的输出"""
    intent: TradeIntent
    executed: bool
    fill_price: Optional[float] = None
    position_size: float = 0.0
    error: Optional[str] = None
    timestamp: datetime = field(default_factory=datetime.now)

这套数据结构的好处是：序列化方便、类型检查友好、日志清晰。

信号扫描模块

核心逻辑：拉行情 → 算指标 → 匹配条件 → 产出 Signal。

import pandas as pd
import numpy as np
from typing import List

class SignalScanner:
    def __init__(self, data_fetcher):
        """
        data_fetcher: 行情获取接口，需实现 fetch(symbol, timeframe, limit) -> DataFrame
        """
        self.fetcher = data_fetcher

    def _calc_indicators(self, df: pd.DataFrame) -> pd.DataFrame:
        df = df.copy()
        df["ma_fast"] = df["close"].rolling(10).mean()
        df["ma_slow"] = df["close"].rolling(30).mean()
        df["atr"] = (df["high"] - df["low"]).rolling(14).mean()
        # RSI
        delta = df["close"].diff()
        gain = delta.clip(lower=0).rolling(14).mean()
        loss = (-delta.clip(upper=0)).rolling(14).mean()
        rs = gain / loss.replace(0, np.nan)
        df["rsi"] = 100 - 100 / (1 + rs)
        return df

    def scan(self, symbols: List[str], timeframe: str = "1h") -> List[Signal]:
        signals = []
        for symbol in symbols:
            try:
                df = self.fetcher.fetch(symbol, timeframe, limit=100)
                if df is None or len(df) < 35:
                    continue
                df = self._calc_indicators(df)
                last = df.iloc[-1]

                # 金叉 + RSI 未超买
                if (last["ma_fast"] > last["ma_slow"]
                        and df.iloc[-2]["ma_fast"] <= df.iloc[-2]["ma_slow"]
                        and last["rsi"] < 70):
                    signals.append(Signal(
                        symbol=symbol,
                        direction=SignalDirection.LONG,
                        price=last["close"],
                        indicator_values={
                            "ma_fast": round(last["ma_fast"], 4),
                            "ma_slow": round(last["ma_slow"], 4),
                            "rsi": round(last["rsi"], 2),
                            "atr": round(last["atr"], 4),
                        },
                    ))

                # 死叉
                elif (last["ma_fast"] < last["ma_slow"]
                      and df.iloc[-2]["ma_fast"] >= df.iloc[-2]["ma_slow"]
                      and last["rsi"] > 30):
                    signals.append(Signal(
                        symbol=symbol,
                        direction=SignalDirection.SHORT,
                        price=last["close"],
                        indicator_values={
                            "ma_fast": round(last["ma_fast"], 4),
                            "ma_slow": round(last["ma_slow"], 4),
                            "rsi": round(last["rsi"], 2),
                            "atr": round(last["atr"], 4),
                        },
                    ))
            except Exception as e:
                print(f"[Scanner] {symbol} 扫描异常: {e}")
        return signals

注意 data_fetcher 是注入的，方便替换成真实 API 或本地回测数据。指标计算用 pandas 向量化，100 根 K 线毫秒级完成。

市场分析模块

扫描出的原始信号不能直接执行，需要二次过滤。这个模块做三件事：趋势确认、波动率过滤、信号打分。

class MarketAnalyzer:
    def __init__(self, min_confidence: float = 0.6,
                 min_atr_ratio: float = 0.002):
        self.min_confidence = min_confidence
        self.min_atr_ratio = min_atr_ratio

    def _score(self, signal: Signal) -> float:
        """基于指标值给出 0~1 的置信度"""
        score = 0.5
        iv = signal.indicator_values

        # 均线发散度：越大趋势越强
        ma_spread = abs(iv["ma_fast"] - iv["ma_slow"]) / iv["ma_slow"]
        score += min(ma_spread * 10, 0.2)

        # RSI 位置：中位区最健康
        rsi = iv["rsi"]
        if signal.direction == SignalDirection.LONG:
            if 40 <= rsi <= 65:
                score += 0.2
            elif rsi > 70:
                score -= 0.3
        elif signal.direction == SignalDirection.SHORT:
            if 35 <= rsi <= 60:
                score += 0.2
            elif rsi < 30:
                score -= 0.3

        # 波动率过滤
        atr_ratio = iv["atr"] / signal.price
        if atr_ratio < self.min_atr_ratio:
            score -= 0.3

        return max(0.0, min(1.0, score))

    def analyze(self, signals: List[Signal]) -> List[TradeIntent]:
        intents = []
        for sig in signals:
            confidence = self._score(sig)
            if confidence < self.min_confidence:
                continue
            intents.append(TradeIntent(
                symbol=sig.symbol,
                direction=sig.direction,
                price=sig.price,
                confidence=round(confidence, 3),
                reason=f"MA交叉 RSI={sig.indicator_values['rsi']} "
                       f"ATR={sig.indicator_values['atr']}",
            ))
        return intents

打分逻辑是策略可插拔的——换成机器学习模型输出概率也行，只要返回 0~1 的 confidence。

模拟交易引擎

这是核心。需要处理：仓位计算、滑点模拟、手续费、持仓跟踪、盈亏统计。

from collections import defaultdict

class TradeEngine:
    def __init__(self, initial_balance: float = 100000.0,
                 fee_rate: float = 0.0005,
                 slippage: float = 0.0002,
                 risk_per_trade: float = 0.02):
        self.balance = initial_balance
        self.initial_balance = initial_balance
        self.fee_rate = fee_rate
        self.slippage = slippage
        self.risk_per_trade = risk_per_trade
        self.positions = {}  # symbol -> dict
        self.trade_log = []

    def _calc_position_size(self, intent: TradeIntent,
                            atr: float) -> float:
        """基于 ATR 的风险仓位法：单笔亏损不超过总资金的 risk_per_trade"""
        if atr <= 0:
            return 0.0
        risk_amount = self.balance * self.risk_per_trade
        # 假设止损距离为 2 倍 ATR
        stop_distance = atr * 2
        size = risk_amount / stop_distance
        # 不超过可用资金
        max_size = self.balance / intent.price
        return round(min(size, max_size), 6)

    def execute(self, intent: TradeIntent,
                atr: float = 0.0) -> TradeResult:
        symbol = intent.symbol

        # 平仓逻辑
        if intent.direction == SignalDirection.CLOSE:
            return self._close_position(symbol, intent.price)

        # 已有持仓则跳过
        if symbol in self.positions:
            return TradeResult(intent=intent, executed=False,
                               error="已有持仓")

        size = self._calc_position_size(intent, atr)
        if size <= 0:
            return TradeResult(intent=intent, executed=False,
                               error="仓位计算为0")

        # 模拟滑点
        direction_mult = 1 if intent.direction == SignalDirection.LONG else -1
        fill_price = intent.price * (1 + direction_mult * self.slippage)
        cost = fill_price * size
        fee = cost * self.fee_rate

        if cost + fee > self.balance:
            return TradeResult(intent=intent, executed=False,
                               error="余额不足")

        self.balance -= (cost + fee)
        self.positions[symbol] = {
            "direction": intent.direction,
            "entry_price": fill_price,
            "size": size,
            "entry_time": datetime.now(),
            "fee_paid": fee,
        }

        result = TradeResult(intent=intent, executed=True,
                             fill_price=fill_price,
                             position_size=size)
        self.trade_log.append(result)
        return result

    def _close_position(self, symbol: str, price: float) -> TradeResult:
        if symbol not in self.positions:
            return TradeResult(
                intent=TradeIntent(symbol, SignalDirection.CLOSE,
                                   price, 0, "无持仓"),
                executed=False, error="无持仓可平")

        pos = self.positions.pop(symbol)
        direction_mult = 1 if pos["direction"] == SignalDirection.LONG else -1
        exit_price = price * (1 - direction_mult * self.slippage)
        proceeds = exit_price * pos["size"]
        exit_fee = proceeds * self.fee_rate
        pnl = (exit_price - pos["entry_price"]) * direction_mult * pos["size"] \
              - pos["fee_paid"] - exit_fee

        self.balance += (proceeds - exit_fee)

        intent = TradeIntent(symbol, SignalDirection.CLOSE, price,
                            1.0, f"平仓 PnL={pnl:.2f}")
        result = TradeResult(intent=intent, executed=True,
                             fill_price=exit_price,
                             position_size=pos["size"])
        self.trade_log.append(result)
        return result

    def stats(self) -> dict:
        total_pnl = self.balance - self.initial_balance
        return {
            "balance": round(self.balance, 2),
            "total_pnl": round(total_pnl, 2),
            "return_pct": round(total_pnl / self.initial_balance * 100, 2),
            "open_positions": len(self.positions),
            "total_trades": len(self.trade_log),
        }

仓位用 ATR 风险法，比固定金额合理得多。滑点和手续费虽小，但长期累积影响巨大，模拟阶段就要算进去。

推送通知模块

通知模块要解耦——换渠道不影响业务逻辑。

import json
from abc import ABC, abstractmethod

class BaseNotifier(ABC):
    @abstractmethod
    def send(self, title: str, content: str): ...

class ConsoleNotifier(BaseNotifier):
    def send(self, title: str, content: str):
        print(f"\n{'='*40}\n[{title}]\n{content}\n{'='*40}")

class WebhookNotifier(BaseNotifier):
    """通用 webhook，适配钉钉/飞书/Slack"""
    def __init__(self, webhook_url: str):
        self.url = webhook_url

    def send(self, title: str, content: str):
        import requests
        payload = {"msgtype": "text",
                   "text": {"content": f"{title}\n{content}"}}
        try:
            requests.post(self.url, json=payload, timeout=5)
        except Exception as e:
            print(f"[Notifier] 推送失败: {e}")

class NotifyService:
    def __init__(self, notifiers: list):
        self.notifiers = notifiers

    def notify_trade(self, result: TradeResult):
        if not result.executed:
            return
        title = f"模拟成交 {result.intent.symbol}"
        content = (f"方向: {result.intent.direction.value}\n"
                   f"价格: {result.fill_price}\n"
                   f"数量: {result.position_size}\n"
                   f"理由: {result.intent.reason}")
        for n in self.notifiers:
            n.send(title, content)

    def notify_stats(self, stats: dict):
        content = json.dumps(stats, ensure_ascii=False, indent=2)
        for n in self.notifiers:
            n.send("账户统计", content)

主循环组装

用 APScheduler 把四个模块串起来：

from apscheduler.schedulers.blocking import BlockingScheduler

class TradingSystem:
    def __init__(self, scanner, analyzer, engine, notifier, symbols):
        self.scanner = scanner
        self.analyzer = analyzer
        self.engine = engine
        self.notifier = notifier
        self.symbols = symbols

    def run_once(self):
        print(f"\n[{datetime.now():%H:%M:%S}] 开始扫描...")
        signals = self.scanner.scan(self.symbols)
        print(f"  原始信号: {len(signals)}")

        intents = self.analyzer.analyze(signals)
        print(f"  过滤后意图: {len(intents)}")

        for intent in intents:
            atr = 0.0
            # 从信号里取 ATR（实际项目可缓存）
            result = self.engine.execute(intent, atr=atr)
            self.notifier.notify_trade(result)

        self.notifier.notify_stats(self.engine.stats())

    def start(self, interval_minutes: int = 5):
        scheduler = BlockingScheduler()
        scheduler.add_job(self.run_once, "interval",
                          minutes=interval_minutes)
        print(f"系统启动，每 {interval_minutes} 分钟扫描一次")
        try:
            scheduler.start()
        except (KeyboardInterrupt, SystemExit):
            print("系统停止")

关键技术选型说明

  • 调度：APScheduler，比手写 while True + sleep 稳，支持 cron 表达式
  • 数据层：SQLite 足够，单文件、零配置；高频场景换 TimescaleDB
  • 指标计算：pandas 向量化，不要用 for 循环逐行算
  • HTTP 请求：requests + 重试装饰器，或 httpx（支持异步）
  • 配置管理：pydantic-settings 读环境变量，别硬编码 API Key
  • 日志：loguru 或标准 logging，输出到文件 + 控制台

扩展方向

这套架构的扩展点都在模块边界上：

  1. 信号扫描：加新策略只需新增 scan 方法，不影响其他模块
  2. 市场分析：换成 ML 模型打分，接口不变
  3. 交易引擎：接真实交易所 API，替换 execute 内部实现
  4. 通知：加 Telegram、邮件，实现 BaseNotifier 即可

架构的价值不在于代码多复杂，而在于改动成本可控。一个新策略从想法到上线，只动 SignalScanner 一个文件——
