模拟交易系统架构设计：从信号扫描到自动执行

2026-09-01 Python自动化

模拟交易系统（Paper Trading System）的价值不在于帮你赚钱，而在于验证你的策略逻辑、参数稳定性以及执行链路是否可靠。实盘与模拟最大的差异在于滑点、延迟和撮合规则，但架构设计的核心——模块解耦、数据流管理、异常处理——是完全一致的。本文分享一套我在实战中打磨过的架构，直接面向Python，代码可参考运行。

1. 系统总体架构

整个系统分为四个核心模块，外加一个调度中枢：

+-------------------+      +-------------------+      +-------------------+
|   信号扫描模块     | ---> |   市场分析模块     | ---> |   模拟交易引擎     |
| (Signal Scanner)  |      | (Market Analyzer) |      | (Paper Engine)    |
+-------------------+      +-------------------+      +-------------------+
         ^                         ^                         |
         |                         |                         v
+-------------------+      +-------------------+      +-------------------+
|   数据源适配器     |      |   特征计算器       |      |   推送通知模块     |
| (Data Feeder)     |      | (Feature Calc)    |      | (Notifier)        |
+-------------------+      +-------------------+      +-------------------+

数据流向：外部行情数据 → 数据源适配器 → 信号扫描模块 → 市场分析模块（特征计算）→ 模拟交易引擎（撮合/持仓管理）→ 推送通知模块（Telegram/邮件/日志）。

核心原则：模块之间不直接调用，通过消息队列（或简单的queue.Queue）解耦。这样任何一个模块崩溃或升级，不影响其他模块运行。

2. 模块职责划分与代码骨架

2.1 数据源适配器（Data Feeder）

这个模块负责对接不同数据源（行情API、CSV文件、数据库），统一输出标准化的Tick或Bar对象。这是整个系统的“地基”。

# data_feeder.py
import time
import queue
from dataclasses import dataclass
from typing import Optional

@dataclass
class Bar:
    symbol: str
    timestamp: int  # Unix timestamp (s)
    open: float
    high: float
    low: float
    close: float
    volume: float

class BaseFeeder:
    """所有数据源的基类，定义统一接口"""
    def __init__(self, symbol: str, queue: queue.Queue):
        self.symbol = symbol
        self.queue = queue

    def run(self):
        raise NotImplementedError

    def _push(self, bar: Bar):
        self.queue.put(bar)

class CSVFeeder(BaseFeeder):
    """从CSV文件读取历史数据，模拟实时推送"""
    def __init__(self, symbol: str, csv_path: str, queue: queue.Queue):
        super().__init__(symbol, queue)
        self.csv_path = csv_path

    def run(self):
        import pandas as pd
        df = pd.read_csv(self.csv_path, parse_dates=['timestamp'])
        for _, row in df.iterrows():
            bar = Bar(
                symbol=self.symbol,
                timestamp=int(row['timestamp'].timestamp()),
                open=row['open'],
                high=row['high'],
                low=row['low'],
                close=row['close'],
                volume=row['volume']
            )
            self._push(bar)
            time.sleep(1)  # 模拟实时推送间隔，实际行情用 websocket 不需要 sleep

2.2 信号扫描模块（Signal Scanner）

该模块从队列中消费Bar数据，运行策略逻辑，产出“信号”对象。信号只包含方向（多/空/平）和强度，不包含仓位大小——仓位管理交给交易引擎。

# signal_scanner.py
import queue
import threading
from dataclasses import dataclass
from enum import Enum

class SignalType(Enum):
    BUY = 1
    SELL = -1
    EXIT = 0

@dataclass
class Signal:
    symbol: str
    type: SignalType
    strength: float  # 0~1，用于仓位计算
    timestamp: int

class BaseStrategy:
    """策略基类，子类实现 generate_signal 方法"""
    def generate_signal(self, bar: Bar) -> Optional[Signal]:
        raise NotImplementedError

class MaCrossStrategy(BaseStrategy):
    """双均线策略示例：快线上穿慢线做多，下穿做空"""
    def __init__(self, fast_window: int = 5, slow_window: int = 20):
        self.fast_window = fast_window
        self.slow_window = slow_window
        self._prices = []

    def generate_signal(self, bar: Bar) -> Optional[Signal]:
        self._prices.append(bar.close)
        if len(self._prices) < self.slow_window:
            return None

        # 只保留最近 slow_window 个价格
        self._prices = self._prices[-self.slow_window:]

        fast_ma = sum(self._prices[-self.fast_window:]) / self.fast_window
        slow_ma = sum(self._prices[-self.slow_window:]) / self.slow_window

        # 判断交叉
        if len(self._prices) >= self.slow_window + 1:
            prev_fast = sum(self._prices[-self.fast_window-1:-1]) / self.fast_window
            prev_slow = sum(self._prices[-self.slow_window-1:-1]) / self.slow_window
            if prev_fast <= prev_slow and fast_ma > slow_ma:
                return Signal(symbol=bar.symbol, type=SignalType.BUY, strength=0.5, timestamp=bar.timestamp)
            elif prev_fast >= prev_slow and fast_ma < slow_ma:
                return Signal(symbol=bar.symbol, type=SignalType.SELL, strength=0.5, timestamp=bar.timestamp)
        return None

class SignalScanner(threading.Thread):
    def __init__(self, data_queue: queue.Queue, signal_queue: queue.Queue, strategy: BaseStrategy):
        super().__init__()
        self.data_queue = data_queue
        self.signal_queue = signal_queue
        self.strategy = strategy
        self._stop_event = threading.Event()

    def run(self):
        while not self._stop_event.is_set():
            try:
                bar = self.data_queue.get(timeout=1)
            except queue.Empty:
                continue

            signal = self.strategy.generate_signal(bar)
            if signal:
                self.signal_queue.put(signal)
                print(f"[Signal] {signal.timestamp} {signal.symbol} {signal.type.name} strength={signal.strength}")

    def stop(self):
        self._stop_event.set()

2.3 市场分析模块（Market Analyzer）

这个模块不是必须的，但建议独立出来。它负责计算技术指标、市场状态（趋势/震荡）、风险指标（波动率、最大回撤），供信号扫描模块和交易引擎共同调用。这里做一个简单的特征计算器：

# market_analyzer.py
import numpy as np

class MarketAnalyzer:
    """计算市场特征，供策略和风控使用"""
    def __init__(self, max_window: int = 100):
        self.max_window = max_window
        self._close_prices = []

    def update(self, close: float):
        self._close_prices.append(close)
        if len(self._close_prices) > self.max_window:
            self._close_prices.pop(0)

    def volatility(self) -> float:
        """最近20根K线的年化波动率"""
        if len(self._close_prices) < 20:
            return 0.0
        returns = np.diff(self._close_prices[-20:]) / self._close_prices[-20:-1]
        return float(np.std(returns) * np.sqrt(252))

    def trend_direction(self) -> int:
        """简单线性回归斜率判断趋势方向"""
        if len(self._close_prices) < 30:
            return 0
        x = np.arange(len(self._close_prices[-30:]))
        y = np.array(self._close_prices[-30:])
        slope = np.polyfit(x, y, 1)[0]
        if slope > 0.01:
            return 1
        elif slope < -0.01:
            return -1
        return 0

2.4 模拟交易引擎（Paper Engine）

这是系统的核心。它接收信号，维护虚拟账户（余额、持仓、订单），模拟撮合（按当前Bar收盘价成交，可加滑点），并生成交易记录。

# paper_engine.py
import queue
import threading
from dataclasses import dataclass, field
from typing import Dict, List

@dataclass
class Position:
    symbol: str
    quantity: float = 0.0
    avg_price: float = 0.0

@dataclass
class TradeRecord:
    timestamp: int
    symbol: str
    side: str  # 'buy' / 'sell'
    price: float
    quantity: float
    pnl: float = 0.0

class PaperEngine(threading.Thread):
    def __init__(self, signal_queue: queue.Queue, initial_cash: float = 100000.0, slippage: float = 0.001):
        super().__init__()
        self.signal_queue = signal_queue
        self.cash = initial_cash
        self.positions: Dict[str, Position] = {}
        self.trades: List[TradeRecord] = []
        self.slippage = slippage  # 模拟滑点比例
        self._stop_event = threading.Event()
        self._lock = threading.Lock()

    def run(self):
        while not self._stop_event.is_set():
            try:
                signal = self.signal_queue.get(timeout=1)
            except queue.Empty:
                continue
            self._execute_signal(signal)

    def _execute_signal(self, signal: Signal):
        with self._lock:
            pos = self.positions.get(signal.symbol, Position(symbol=signal.symbol))
            # 这里简化：每次信号只操作固定仓位比例，实际可以用ATR或风险模型
            trade_qty = 100  # 固定100股/张

            if signal.type == SignalType.BUY:
                # 模拟成交价 = 当前价 + 滑点
                # 注意：这里没有直接获取当前价，需要从信号或外部传入，实际中可维护最新价表
                # 为简化，我们假设信号携带了价格（实际实现中应传入）
                price = signal.strength  # 仅作演示，实际应传入最新价格
                cost = price * trade_qty
                if self.cash >= cost:
                    self.cash -= cost
                    # 更新持仓
                    total_qty = pos.quantity + trade_qty
                    pos.avg_price = (pos.avg_price * pos.quantity + cost) / total_qty if total_qty > 0 else price
                    pos.quantity = total_qty
                    self.positions[signal.symbol] = pos
                    self.trades.append(TradeRecord(signal.timestamp, signal.symbol, 'buy', price, trade_qty))
                    print(f"[Trade] BUY {trade_qty} {signal.symbol} @ {price:.2f}")

            elif signal.type == SignalType.SELL:
                if pos.quantity >= trade_qty:
                    price = signal.strength
                    revenue = price * trade_qty
                    self.cash += revenue
                    # 计算 PnL
                    pnl = (price - pos.avg_price) * trade_qty
                    pos.quantity -= trade_qty
                    if pos.quantity == 0:
                        del self.positions[signal.symbol]
                    else:
                        self.positions[signal.symbol] = pos
                    self.trades.append(TradeRecord(signal.timestamp, signal.symbol, 'sell', price, trade_qty, pnl))
                    print(f"[Trade] SELL {trade_qty} {signal.symbol} @ {price:.2f} PnL={pnl:.2f}")

            elif signal.type == SignalType.EXIT:
                # 平仓逻辑
                if pos.quantity > 0:
                    price = signal.strength
                    revenue = price * pos.quantity
                    self.cash += revenue
                    pnl = (price - pos.avg_price) * pos.quantity
                    self.trades.append(TradeRecord(signal.timestamp, signal.symbol, 'exit', price, pos.quantity, pnl))
                    print(f"[Trade] EXIT {pos.quantity} {signal.symbol} @ {price:.2f} PnL={pnl:.2f}")
                    del self.positions[signal.symbol]

    def get_account_summary(self) -> dict:
        with self._lock:
            total_value = self.cash
            for sym, pos in self.positions.items():
                # 实际中需要最新价格，这里用 avg_price 代替
                total_value += pos.quantity * pos.avg_price
            return {
                "cash": self.cash,
                "positions": {k: (v.quantity, v.avg_price) for k, v in self.positions.items()},
                "total_value": total_value,
                "trade_count": len(self.trades)
            }

    def stop(self):
        self._stop_event.set()

2.5 推送通知模块（Notifier）

用于实时推送信号和交易结果，避免盯盘。这里以Telegram为例，但为了不引入外部依赖，先提供一个抽象接口和日志实现：

# notifier.py
import logging
from typing import Optional

class BaseNotifier:
    def send(self, message: str):
        raise NotImplementedError

class LogNotifier(BaseNotifier):
    """默认实现：输出到日志文件和控制台"""
    def __init__(self, log_file: str = "trading.log"):
        logging.basicConfig(
            filename=log_file,
            level=logging.INFO,
            format='%(asctime)s - %(message)s'
        )
        self.logger = logging.getLogger("paper_trading")

    def send(self, message: str):
        self.logger.info(message)
        print(f"[Notifier] {message}")

# 可选：Telegram 实现
class TelegramNotifier(BaseNotifier):
    def __init__(self, token: str, chat_id: str):
        # 这里需要 requests 库，可按需安装
        self.token = token
        self.chat_id = chat_id

    def send(self, message: str):
        import requests
        url = f"https://api.telegram.org/bot{self.token}/sendMessage"
        params = {"chat_id": self.chat_id, "text": message}
        requests.post(url, data=params)

3. 系统调度与启动

我们用一个主脚本来组装所有模块，并启动线程。这是整个系统的“总装线”：

# main.py
import queue
import time

from data_feeder import CSVFeeder
from signal_scanner import SignalScanner, MaCrossStrategy
from paper_engine import PaperEngine
from notifier import LogNotifier

def main():
    # 创建消息队列
    data_queue = queue.Queue(maxsize=1000)
    signal_queue = queue.Queue(maxsize=100)

    # 初始化模块
    feeder = CSVFeeder(
        symbol="BTCUSDT",
        csv_path="./data/btc_1h.csv",  # 假设有历史数据文件
        queue=data_queue
    )

    strategy = MaCrossStrategy(fast_window=5, slow_window=20)
    scanner = SignalScanner(data_queue=data_queue, signal_queue=signal_queue, strategy=strategy)

    engine = PaperEngine(signal_queue=signal_queue, initial_cash=100000.0, slippage=0.001)

    notifier = LogNotifier(log_file="./paper_trading.log")

    # 启动线程
    scanner.start()
    engine.start()

    # 运行数据源（这里用主线程跑，方便 Ctrl+C 退出）
    try:
        feeder.run()
    except KeyboardInterrupt:
        print("Shutting down...")
    finally:
        scanner.stop()
        engine.stop()
        scanner.join()
        engine.join()

    # 输出账户汇总
    summary = engine.get_account_summary()
    notifier.send(f"Final Summary: {summary}")

if __name__ == "__main__":
    main()

4. 关键技术选型与架构决策

4.1 为什么用线程而不是多进程？

  • 模拟交易系统I/O密集（等待行情、网络推送），线程足够，且共享内存方便（持仓、账户数据）。
  • 如果策略是CPU密集型（如机器学习预测），建议将信号扫描模块独立为多进程，通过ZeroMQ或Redis队列通信。

4.2 队列的作用

队列在这里不仅解耦模块，还起到了流量削峰的作用。当行情波动大时，数据队列会堆积，但信号扫描模块消费速度跟不上时，可以丢弃旧数据（queue.Queue的maxsize + put_nowait），避免内存爆炸。

4.3 模拟撮合的关键细节

  • 滑点：用slippage参数模拟，实际中可以根据波动率动态调整。
  • 成交价：真实系统中，信号应该携带bar对象，交易引擎用bar.close作为成交价。上面的代码为了简化，用signal.strength代替，实际中务必传入价格。
  • 手续费：在_execute_signal中，每次成交扣除commission，例如cost = price * qty * (1 + commission_rate)。

4.4 扩展性设计

  • 新策略：只需继承BaseStrategy，实现generate_signal，然后在main.py中替换即可。
  • 新数据源：继承BaseFeeder，重写run方法。
  • 新通知渠道：实现BaseNotifier接口。
