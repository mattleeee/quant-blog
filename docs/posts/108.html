山寨币'庄家吸筹'策略的量化证伪：从直觉到参数网格到跨周期

2026-11-21 量化回测

山寨币是庄家市，这是很多人的共识。由此衍生出一套非常顺滑的操作直觉：

  • 底部横盘、缩量后温和放量，是庄家在吸筹；
  • 跟着吸筹信号买入，拿 2~3 天就走；
  • 止盈比止损设成 2:1，就算庄家插针洗盘，亏也亏不多；
  • 位置低、有庄、盈亏比占优，长期应该正期望。

这个逻辑每一环单看都成立，合起来更像“稳赚”。问题在于：直觉里“底部横盘放量”这几个字，从来没有被精确定义过。不定义就无法回测，不回测就永远停留在“我觉得”。

这篇文章记录的是把上述直觉翻译成可回测规则、跑参数网格、再做跨周期复验的完整过程。结论先放这里：在量价数据上，这个框架不成立。下面是它怎么被证伪的。

二、把直觉翻译成可回测规则

2.1 信号定义

回测的第一步是把模糊描述变成可计算的布尔条件。逐条映射：

直觉描述 量化规则
位置低 收盘价位于过去 30 天区间（high-low）的下半部
波动收敛 ATR/price 相比 40 根之前收窄
温和放量 成交量在 1.5~5 倍均量之间
阳线启动 当根涨幅 2%~8%

出场规则：TP +6% / SL -3% / 持有 3 根 K 线超时平仓。

2.2 数据与样本

  • 标的：20 个山寨币
  • 周期：4h
  • 区间：200 天
  • 单笔按信号出现即入场，同一标的持仓期间不重复开仓

2.3 回测代码结构

不依赖任何回测框架，用 pandas 直接算，逻辑透明、便于改参数：

import numpy as np
import pandas as pd

def add_indicators(df: pd.DataFrame, vol_win=20, atr_win=14) -> pd.DataFrame:
    df = df.copy()
    # 30天区间（4h，一天6根，30天=180根）
    df["hh30"] = df["high"].rolling(180).max()
    df["ll30"] = df["low"].rolling(180).min()
    df["pos"] = (df["close"] - df["ll30"]) / (df["hh30"] - df["ll30"] + 1e-12)

    # ATR
    tr = pd.concat([
        df["high"] - df["low"],
        (df["high"] - df["close"].shift()).abs(),
        (df["low"] - df["close"].shift()).abs(),
    ], axis=1).max(axis=1)
    df["atr"] = tr.rolling(atr_win).mean()
    df["atr_ratio"] = df["atr"] / df["close"]

    # 均量
    df["vol_ma"] = df["volume"].rolling(vol_win).mean()
    df["vol_mult"] = df["volume"] / (df["vol_ma"] + 1e-12)

    # 涨幅
    df["ret"] = df["close"] / df["close"].shift() - 1
    return df


def gen_signal(df: pd.DataFrame, pos_max=0.5, atr_shrink=0.9,
               vol_lo=1.5, vol_hi=5.0, ret_lo=0.02, ret_hi=0.08) -> pd.Series:
    cond = (
        (df["pos"] < pos_max) &
        (df["atr_ratio"] < df["atr_ratio"].shift(40) * atr_shrink) &
        (df["vol_mult"].between(vol_lo, vol_hi)) &
        (df["ret"].between(ret_lo, ret_hi))
    )
    return cond.fillna(False)


def backtest(df: pd.DataFrame, signal: pd.Series, tp=0.06, sl=0.03,
             hold_max=3) -> pd.DataFrame:
    """逐根模拟，返回每笔交易记录。"""
    trades = []
    i = 0
    n = len(df)
    idx = df.index
    while i < n - 1:
        if not signal.iloc[i]:
            i += 1
            continue
        entry = df["close"].iloc[i]
        tp_px, sl_px = entry * (1 + tp), entry * (1 - sl)
        exit_px, exit_reason, bars = None, None, 0
        for j in range(i + 1, min(i + 1 + hold_max, n)):
            bars = j - i
            hi, lo = df["high"].iloc[j], df["low"].iloc[j]
            # 保守假设：同根先触发 SL
            if lo <= sl_px:
                exit_px, exit_reason = sl_px, "SL"
                break
            if hi >= tp_px:
                exit_px, exit_reason = tp_px, "TP"
                break
        if exit_px is None:
            j = min(i + hold_max, n - 1)
            exit_px, exit_reason, bars = df["close"].iloc[j], "TIME", j - i
        trades.append({
            "entry_time": idx[i], "exit_time": idx[min(i + bars, n - 1)],
            "entry": entry, "exit": exit_px, "reason": exit_reason,
            "bars": bars, "ret": exit_px / entry - 1,
        })
        i += bars + 1  # 持仓期跳过
    return pd.DataFrame(trades)

2.4 基准结果：就差一口气

20 个标的、200 天 4h 数据，基准参数（TP6/SL3/持有3根）跑出来：

  • 总交易：160 笔
  • 每笔期望：-0.24%
  • 胜率：32.5%
  • 出场分布：SL 107 次 vs TP 48 次（其余超时平仓）

保本胜率线是 33.3%（因为 2:1 盈亏比，胜率 p 满足 p·2 − (1−p)·1 = 0）。实际 32.5%，差 0.8 个百分点。

这个数字非常“有迷惑性”——它看起来像“再优化一点点就正了”。很多策略就是死在这种“就差一口气”的错觉上，然后被反复调参直到过拟合。所以下一步不是庆祝接近保本，而是主动做参数网格，看这口气能不能真的补上。

三、参数网格：把“差一口气”拆开看

3.1 网格设计

围绕两个维度做组合：

  1. TP/SL 组合：从 6/3 出发，扩到 12/6，共 8 组变体（保持约 2:1 的比例，同时改变绝对幅度）；
  2. 位置过滤收紧：pos_max 从 0.5 降到 0.4、0.3；
  3. 持仓时间：2 / 3 / 4 根。
from itertools import product

results = []
for tp, sl in [(0.06,0.03),(0.07,0.035),(0.08,0.04),(0.09,0.045),
               (0.10,0.05),(0.11,0.055),(0.12,0.06),(0.08,0.03)]:
    for pos_max in [0.5, 0.4, 0.3]:
        for hold_max in [2, 3, 4]:
            all_trades = []
            for sym, df in data.items():
                d = add_indicators(df)
                sig = gen_signal(d, pos_max=pos_max)
                t = backtest(d, sig, tp=tp, sl=sl, hold_max=hold_max)
                t["symbol"] = sym
                all_trades.append(t)
            tr = pd.concat(all_trades, ignore_index=True)
            if len(tr) < 30:
                continue
            mean_ret = tr["ret"].mean()
            t_stat = mean_ret / (tr["ret"].std(ddof=1) / np.sqrt(len(tr)))
            results.append({
                "tp": tp, "sl": sl, "pos_max": pos_max, "hold_max": hold_max,
                "n": len(tr), "mean_ret": mean_ret,
                "win_rate": (tr["ret"] > 0).mean(), "t": t_stat,
            })

res = pd.DataFrame(results).sort_values("mean_ret", ascending=False)
print(res.head(10))

3.2 最好的变体，以及它为什么不算数

网格里表现最好的一组是 TP8/SL4：

  • 每笔期望：+0.4%
  • 但 t = 0.88，远低于显著性门槛（约 2）；
  • 更致命的是前后半段收益 -8% / +70%：整个正期望几乎全部来自后半段行情，前半段是亏的。

这意味着它不是一个“稳定的小优势”，而是“某段行情恰好配合了这个形态”。样本内挑出来的最好参数 + 严重依赖单一行情阶段 + t 值不显著，三条同时成立，基本可以判定为过拟合而非 edge。

参数网格在这里的作用不是“找到好参数”，而是证明“差一口气”不是参数没调好，而是框架本身没有优势——160 笔的基准已经是负的，网格里能翻正的都站不住统计检验。

四、跨周期复验：换到 1h 全线为负

参数网格还有一个隐患：所有结论都建立在 4h 这一个周期上。如果信号真有量价逻辑，换周期应该至少方向一致。于是把同一套规则搬到 1h 数据上复验（区间与标的对齐，指标窗口按根数同比缩放）。

结果：1h 上所有变体全部为负，没有一组翻正。

这个结果比 4h 的 -0.24% 更有信息量：它说明 4h 上那个“接近保本”的数字，很可能只是特定采样频率下的噪声，而不是被周期掩盖的真实信号。一个在多个周期上方向不一致的形态，不配被称为策略。

五、为什么“低位放量阳线”会失效

回到信号本身。这个形态在阴跌市里的真实含义，和直觉正好相反：

  • 低位：阴跌市里“低位”是常态，30 天区间下半部筛出来的大量样本，本身就是下跌趋势中的反弹点；
  • 温和放量 + 阳线：在下跌趋势里，这更常见的是出货前的假启动——拉一根阳线吸引跟风盘，然后继续下；
  • 2:1 盈亏比：在假启动占多数的样本里，SL 被触发 107 次、TP 只有 48 次，盈亏比的优势被胜率劣势吃干净。

换句话说，“低位放量阳线”不是吸筹的充分条件，甚至不是必要条件。它只是一个在上涨市里看起来很像吸筹、在下跌市里系统性偏向出货的形态。而山寨币样本期里，阴跌占了相当比例。

这也是为什么基准胜率卡在 32.5%：它不是“运气差一点”，而是形态本身的期望分布就落在保本线之下。

六、真正的收获：盘感里不可量化的部分

这次证伪最有价值的副产品，是搞清了一件事：

散户口中的“庄家吸筹”，很大一部分是对特定标的、特定庄家行为模式的熟悉——知道这个币的庄家习惯怎么洗、习惯拉几根、习惯在什么时间点动手。这部分经验高度依赖个体观察，恰恰是 K 线重构不出来的。

量价数据能编码“位置、波动、量比、涨幅”，但编码不了“这个庄家上次是怎么骗我的”。把可编码的部分抽出来做回测，得到的只是一个去掉了核心信息的近似形态，它失效是合理的。

所以结论不是“庄家吸筹不存在”，而是：“低位放量阳线”这个可量化的代理变量，不足以承载“吸筹”这个判断。要验证真正的吸筹逻辑，需要订单流、挂单簿、链上转账、地址行为等更高维的数据，而不是 OHLCV 的形态组合。

七、证伪也是产出

最后算一笔账：

  • 这次证伪花掉的是：几小时写代码 + 跑网格 + 跨周期复验；
  • 它避免的是：拿真金白银按这个直觉去交易 160 笔、每笔期望 -0.24%、还要叠加手续费和滑点的学费。

负结果的价值在于它可复用：以后再看到“低位放量就是吸筹”的说法，可以直接引用这次 160 笔、-0.24%、32.5% 胜率、1h 全线为负的数据，而不是重新凭感觉判断一遍。

附上本文用到的完整代码结构，方便复现和改造：

# 完整流程骨架
# 1. 数据加载：data = {symbol: df[['open','high','low','close','volume']]}
# 2. 指标：d = add_indicators(df)
# 3. 信号：sig = gen_signal(d, pos_max=..., atr_shrink=..., vol_lo=..., vol_hi=...)
# 4. 回测：tr = backtest(d, sig, tp=..., sl=..., hold_max=...)
# 5. 网格：遍历 tp/sl/pos_max/hold_max，统计 mean_ret / win_rate / t
# 6. 复验：换周期（4h -> 1h）重跑步骤 2~5，检查方向一致性
# 7. 分段检验：按时间切前后半段，看收益是否依赖单一行情

判断一个形态值不值得继续投入，看三条就够：样本内期望是否显著为正、t 值是否过线、跨周期方向是否一致。三条缺一条，就应该按证伪处理，而不是继续调参。
