What this is

Practical engineering notes on Python quantitative trading, backtesting, scheduled automation, and surviving corporate networks.

This is the English edition of a bilingual blog. The Chinese edition lives at the site root; everything under /en is written in English.

Topics

  • Windows automation: Task Scheduler fleets, silent execution, retries, health checks
  • Encoding survival: UTF-8 vs GBK, PowerShell BOM rules, bulletproof batch files
  • Corporate networking: HTTPS interception, blocked endpoints, GB28181/SIP debugging
  • Static site delivery: GitHub Pages via the Contents API, free domains, HTTPS

Author
